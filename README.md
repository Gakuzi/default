# Яндекс Транспорт (Архангельск) для Home Assistant

Интеграция для отслеживания движения общественного транспорта в г. Архангельск через данные Яндекс.Карт.

## Возможности
- Настройка через UI (Config Flow): добавление остановки по ссылке или ID
- Выбор нужных маршрутов чекбоксами
- Главный сенсор остановки (совместим с карточками транспорта)
- Отдельные сенсоры по каждому выбранному маршруту с временем прибытия
- Асинхронный опрос без блокировки потоков Home Assistant
- Поддержка HACS

## Установка через HACS
1. Откройте HACS -> Интеграции -> Пользовательские репозитории.
2. Добавьте URL: `https://github.com/Gakuzi/yandex_bus_arkhangelsk` (Тип: Integration).
3. Установите интеграцию и перезапустите Home Assistant.

## Ручная установка
Скопируйте папку `custom_components/yandex_bus_arkhangelsk` в каталог `custom_components` вашего Home Assistant и перезагрузите сервер.
