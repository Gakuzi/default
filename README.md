# Яндекс Транспорт (Архангельск) для Home Assistant

Пользовательский компонент для Home Assistant, позволяющий отслеживать движение и время прибытия общественного транспорта в г. Архангельск в реальном времени.

## Возможности
- Добавление остановок по обычной ссылке с Яндекс.Карт.
- Автоматическое определение названия остановки и списка проходящих маршрутов.
- Выбор нужных номеров автобусов галочками при настройке.
- Отдельный сенсор на каждый выбранный маршрут с точным прогнозом прибытия (в минутах или по расписанию).
- Сводный сенсор остановки (передает полный список маршрутов в атрибуты, совместим с Lovelace-карточками транспорта).
- Асинхронный опрос данных без блокировки интерфейса и ресурсов системы.

---

## Как получить ссылку на остановку
1. Перейдите на [Яндекс.Карты (Архангельск)](https://yandex.ru/maps/20/arkhangelsk/?l=masstransit).
2. Найдите нужную остановку на карте и кликните по ней.
3. Скопируйте URL из адресной строки браузера. Он выглядит так:
   `https://yandex.ru/maps/20/arkhangelsk/stops/stop__9831201/?l=masstransit`
4. Вставьте эту ссылку при добавлении интеграции. Номер остановки извлечется автоматически.

## Установка

### Вариант 1: Через HACS (рекомендуется)
1. Откройте **HACS** -> раздел **Интеграции**.
2. В верхнем правом углу нажмите три точки -> **Пользовательские репозитории** (Custom repositories).
3. В поле **Репозиторий** вставьте: `https://github.com/Gakuzi/yandex_bus_arkhangelsk`
4. В поле **Тип** выберите: `Интеграция` (Integration) и нажмите **Добавить**.
5. Найдите интеграцию в каталоге, нажмите **Загрузить** и перезапустите Home Assistant.

### Вариант 2: Вручную
1. Скачайте содержимое репозитория.
2. Скопируйте папку `custom_components/yandex_bus_arkhangelsk` в директорию `custom_components` вашего сервера Home Assistant.
3. Перезапустите Home Assistant.

---

## Настройка
1. В интерфейсе Home Assistant перейдите в **Настройки** -> **Устройства и службы** -> **Добавить интеграцию**.
2. Найдите **Яндекс Транспорт (Архангельск)**.
3. Вставьте ссылку на остановку.
4. На следующем шаге отметьте галочками интересующие маршруты.
